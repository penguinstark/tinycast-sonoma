extensions, too.

[Explore all features →](docs/README.md)

## Install

A frozen macOS 14 edition of Tinycast. Install with Homebrew:

```sh
brew install --cask tinycast-sonoma
```

Updates arrive through `brew upgrade`; there is no in-app updater.
